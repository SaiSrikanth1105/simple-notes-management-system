# SNM - Simple Notes Management System

SNM (Simple Notes Management System) is a Flask-based full stack web application that allows users to securely manage notes and files with authentication, OTP verification, search functionality, and modern glassmorphism UI.

---

## Features

- User Registration & Login
- OTP Email Verification
- Session Management
- Add / Update / Delete Notes
- Upload / View / Download / Delete Files
- Search Notes & Files
- Change Password Feature
- Custom Delete Confirmation Modal
- Glassmorphism Dashboard UI
- Responsive and Modern Design

---
